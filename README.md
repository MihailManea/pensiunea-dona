# Oasis Digital

Acționează ca o echipă formată din:

	•	Senior UX/UI Designer

	•	Senior Frontend Developer

	•	Senior Backend Developer

	•	Expert în SEO

	•	Expert în Marketing și Conversie

	•	Expert în CRO (Conversion Rate Optimization)

Construiește un website complet, modern, premium și foarte rapid pentru o pensiune de închiriat.

Cerințe generale

Site-ul trebuie să inspire:

	•	încredere

	•	lux discret

	•	confort

	•	natură

	•	relaxare

	•	profesionalism

Designul trebuie să fie comparabil cu site-urile hotelurilor premium.

Folosește:

	•	HTML5

	•	CSS3

	•	JavaScript modern

	•	Design Responsive (Desktop, Tabletă și Telefon)

	•	Animații fluide

	•	Lazy Loading

	•	SEO complet

	•	Accesibilitate (ARIA)

	•	Optimizare PageSpeed

	•	Cod curat și bine comentat

Paleta de culori:

	•	Alb

	•	Verde închis

	•	Bej

	•	Maro lemn

	•	Gri foarte deschis

Fonturi elegante:

	•	Poppins

	•	Playfair Display

Adaugă:

	•	efecte glassmorphism discrete

	•	umbre moderne

	•	hover elegant

	•	tranziții line

	•	scroll animations

	•	parallax discret

	•	micro-animații

Site-ul trebuie să aibă un aspect premium.

PAGINA 5 – RECENZII

Aspect identic cu Booking și Airbnb.

Stele.

Fotografie utilizator.

Data.

Țara.

Scor.

Afișează aproximativ:

90% recenzii excelente

10% recenzii negative.

Pentru fiecare recenzie negativă afișează imediat dedesubt:

Răspunsul proprietarului.

Acesta trebuie să fie:

politicos

profesionist

empatic

orientat spre soluții

și să demonstreze că situația a fost rezolvată.

Exemple:

“Camera era prea rece.”

↓

Răspuns:

“Vă mulțumim pentru feedback. Între timp am instalat un sistem nou de încălzire și problema a fost complet rezolvată.”

Același lucru pentru orice altă critică.

Scopul este să transformi recenziile negative într-un avantaj de încredere.
